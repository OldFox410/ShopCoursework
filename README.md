# 📦 Магазин — Веб-система учета и аналитической отчетности

Легковесное, высокопроизводительное веб-приложение для автоматизации торгового учета, складских операций, поставок и построения аналитических отчетов. Проект разработан на базе классического серверного рендеринга без избыточных клиентских фреймворков.

---

## 🛠 Технологический стек

* **Бэкенд:** ASP.NET Core MVC (.NET)
* **Доступ к данным:** Dapper (Micro-ORM)
* **База данных:** Microsoft SQL Server (3NF)
* **Архитектура:** CQRS-lite, Repository-lite pattern
* **Фронтенд:** Razor Views, HTML5, CSS3 (серверный рендеринг)

---

## 📊 Основной функционал и отчеты

Система включает в себя нормализованную реляционную базу данных (7 таблиц) и три ключевых аналитических модуля:
1. **Отчет по проданным товарам:** выборка позиций чеков с возможностью фильтрации по минимальной цене и диапазону дат.
2. **Статистика продаж техники:** агрегированные данные по товарным категориям с подсчетом общего объема проданных единиц и итоговой выручки.
3. **Учет сотрудников:** кадровый реестр с динамическим фильтром по наличию детей (`HasChildren`).

---

## 🏗 Архитектура (CQRS-lite)

Для изоляции логики чтения данных используется легковесный шаблон проектирования `DataBaseQuery`:
- Базовый обобщенный класс `DataBaseQuery<TEntity, TDto, TFilter>` инкапсулирует управление подключениями и маппинг через Dapper.
- Специфические SQL-запросы вынесены в отдельные классы (`SalesQuery`, `TechSalesQuery`, `EmployeeQuery`).
- Все входные параметры фильтрации реализованы в виде неизменяемых типов (`record`).
